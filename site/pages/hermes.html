Hermes Agent by Nous Research runs on your machine (or a home server). ChroMind connects the same way as TileSmith and DailyDash: enter you@your-server and the SSH password. ChroMind Bridge opens a private tunnel to Hermes' API on that machine — nothing needs to be exposed to the internet.

On the server

  1. Install and run Hermes with its API server on localhost: 
    API_SERVER_ENABLED=true
API_SERVER_KEY=pick-a-long-random-key
    in ~/.hermes/.env, then: 
    hermes gateway
    It should log API server listening on http://127.0.0.1:8642. Generate a key with openssl rand -hex 24.
  2. Reach the box over SSH — Tailscale is the easy path (100.x.y.z or MagicDNS). You only need a normal SSH login; Hermes itself can stay bound to localhost.

In ChroMind

  1. Start ChroMind Bridge on this computer and paste its token under Settings → Bridge.
  2. Settings → AI providers → Hermes Agent:
    FieldValue
    Addressyou@100.x.y.z (add :port if SSH is not on 22)
    PasswordYour SSH password
    Modelhermes-agent, or your profile name
    ProfileOptional, for multi-profile setups (/p/<profile>)
    Memory keySent as X-Hermes-Session-Key so Hermes scopes long-term memory to ChroMind
  3. Click Test. The Bridge SSHs in, tunnels to 127.0.0.1:8642, reads API_SERVER_KEY from the server's ~/.hermes/.env, and lists models. Then pick Hermes from the pill in the panel.

Same login as your other apps

Address is user@host or user@host:port — identical to TileSmith's Server page and DailyDash's server profiles. The Bridge keeps the tunnel open while you chat so Hermes tool chips still stream through.

Hermes on this PC

If Hermes runs on the same machine as the browser, you do not need SSH. Put the API URL in Address and the API key in Password:

FieldValue
Addresshttp://127.0.0.1:8642
PasswordYour API_SERVER_KEY

A bare host like 127.0.0.1 is treated as http://127.0.0.1:8642.

No CORS setup needed

Requests come from the extension (or the Bridge), not a web page, so you don't need API_SERVER_CORS_ORIGINS. ChroMind also drops its Origin header on direct requests.

Give ChroMind a safe profile

Pages are untrusted

Unlike Claude Code / Cursor through the Bridge, Hermes keeps its tools, including terminal access if you enabled it. A web page you ask about could contain text that tries to steer the agent. ChroMind marks page text as untrusted and tells the model to ignore instructions inside it, but the safe setup is a Hermes profile for browsing with only the tools you want here (web search, memory), and that profile name in ChroMind's Profile field.

What you'll see

  • Tool calls appear as chips (web_search, memory …) above the answer while Hermes works.
  • Screenshots and images go to Hermes as image parts, if its model can see.
  • Each message carries the whole chat, so Hermes always has the conversation.
