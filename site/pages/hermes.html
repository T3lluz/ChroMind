Settings → Your server has two fields, like DailyDash and TileSmith: the server and a password. Click Connect, and ChroMind looks for what's running there:

FoundWhat you getPassword
Your t3lluz dashboard (/_api) Hermes' model, plus the Claude, Cursor and OpenCode logins on that machine, each with its depths None (the dashboard is tailnet-only)
Hermes Agent's API server (port 8642) Hermes and its profiles, with tool use shown as it works Hermes' API_SERVER_KEY

The server field takes whatever you have at hand: you@100.64.0.5, my-box, t3lluz.com, http://192.168.1.20:8642. The you@ part and an SSH port are ignored: a browser can't open SSH connections, so ChroMind talks to the server over HTTP, the same way DailyDash does.

Hermes on its own

If the server runs Hermes without the dashboard, let its API server answer on the network:

  1. In the server's ~/.hermes/.env: 
    API_SERVER_ENABLED=true
API_SERVER_HOST=0.0.0.0
API_SERVER_KEY=pick-a-long-random-key
    Make a key with openssl rand -hex 24. Then restart: hermes gateway.
  2. Keep it private. Use Tailscale (100.x.y.z or MagicDNS) or your home network. Don't forward port 8642 to the internet.
  3. In ChroMind: the server's address, and the API_SERVER_KEY as the password (not your SSH password). Click Connect.

Hermes on this computer: use 127.0.0.1 as the server; API_SERVER_HOST can stay as it is.

"Nothing answered"?

Hermes' API listens only on the server itself until you set API_SERVER_HOST=0.0.0.0. ChroMind shows that line with a copy button when it can't reach anything. Also check that this computer is on the same tailnet or network.

Give ChroMind a safe profile

Pages are untrusted

Hermes keeps its tools, including a terminal if you enabled it. A page you ask about could contain text that tries to steer the agent. ChroMind marks page text as untrusted and tells the model to ignore instructions in it, but the safe setup is a Hermes profile for browsing with only the tools you want here (web search, memory), named in the Profile option.

What you'll see

  • In the AI picker, Your server lists what it found. Dashboard models are grouped by where they come from (Claude, Cursor, OpenCode), with their depths.
  • Hermes' tool calls show in the working line (Using web_search) and as chips above the answer.
  • Screenshots go to Hermes as images, if its model can see.
  • Each message carries the whole chat, so Hermes always has the conversation.
  • No CORS setup: requests come from the extension, not a web page, and carry no Origin header.
