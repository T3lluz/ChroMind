Hermes Agent by Nous Research ships an OpenAI-compatible API server. ChroMind connects to it like any chat server, and also shows Hermes' tool progress while it works.

Turn on the API server

  1. Add the API server settings to ~/.hermes/.env on the machine running Hermes: 
    API_SERVER_ENABLED=true
API_SERVER_KEY=pick-a-long-random-key
    The key is required, even on localhost. Generate one with openssl rand -hex 24.
  2. Start the gateway: 
    hermes gateway
    It logs API server listening on http://127.0.0.1:8642.
  3. Fill in ChroMind → Settings → AI providers → Hermes Agent:
    FieldValue
    Server URLhttp://127.0.0.1:8642 (or your server, see below)
    API keyYour API_SERVER_KEY
    Modelhermes-agent, or your profile name
    ProfileOptional, for multi-profile setups (/p/<profile>)
    Memory keySent as X-Hermes-Session-Key so Hermes scopes long-term memory to ChroMind
  4. Click Test. It lists the models the server reports. Then pick Hermes from the pill in the panel.

No CORS setup needed

Requests come from the extension, not a web page, so you don't need API_SERVER_CORS_ORIGINS. ChroMind also drops its Origin header, so a strict allowlist won't block it.

Hermes on another machine

If Hermes runs on a home server, reach it privately rather than exposing it to the internet:

  • Tailscale: set API_SERVER_HOST=0.0.0.0 (or the Tailscale IP) and use http://your-server:8642 from your tailnet.
  • Reverse proxy (Caddy, nginx) with HTTPS in front of 127.0.0.1:8642, then use https://hermes.example.com.

Hermes requires the key on any non-loopback bind. Keep it secret: anyone with it can run your agent.

Give ChroMind a safe profile

Pages are untrusted

Unlike the Bridge, Hermes keeps its tools, including terminal access if you enabled it. A web page you ask about could contain text that tries to steer the agent. ChroMind marks page text as untrusted and tells the model to ignore instructions inside it, but the safe setup is a Hermes profile for browsing with only the tools you want here (web search, memory), and that profile name in ChroMind's Profile field.

What you'll see

  • Tool calls appear as chips (web_search, memory …) above the answer while Hermes works.
  • Screenshots and images go to Hermes as image parts, if its model can see.
  • Each message carries the whole chat, so Hermes always has the conversation.
