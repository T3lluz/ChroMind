ChroMind for Firefox Signed by Mozilla. Updates install on their own.
Add to Firefox
  1. Click Add to Firefox. Firefox asks twice: first Continue to Installation (the add-on comes from this site rather than the add-ons store), then Add.
  2. Allow website access if Firefox asks. ChroMind needs it to read pages and to reach claude.ai, the Bridge and your servers.
  3. Open it. Click the ChroMind button in the toolbar or press Alt+Shift+A. It opens in the sidebar. In Zen, pin it from the toolbar's extension menu.

  • For this session: open about:debugging#/runtime/this-firefox, click Load Temporary Add-on and pick the file below. Firefox removes it when it closes.

ChroMind for Chromium Chrome, Edge, Brave, Vivaldi, Opera, Arc. Chrome 116 or newer.
Download chromind-chrome.zip
  1. Unzip it into a folder you keep, for example Documents/ChroMind. The browser runs the extension from that folder, so don't leave it in Downloads.
  2. Open the extensions page and turn on Developer mode. Paste chrome://extensions in the address bar (Edge: edge://extensions, Brave: brave://extensions) and switch on Developer mode.
  3. Click Load unpacked and pick the folder with manifest.json in it.
  4. Pin it. Click the puzzle piece, pin ChroMind, then click it (or Alt+Shift+A) to open the side panel.

Updating

Download the new zip, unzip it over the same folder, and press the reload arrow on ChroMind's card in chrome://extensions. Your settings and chats stay.

From the repository

Cloned the repo? Load the extension/ folder directly. It has the Chromium manifest.

After installing

ChroMind opens its settings once. Pick the provider that should answer by default. If you're signed in to claude.ai, Claude works right away. See AI providers for the others.
