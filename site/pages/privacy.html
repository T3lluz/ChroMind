What leaves your browser

Only when you send a message or run an action, and only to the provider you picked:

ProviderReceivesGoes to
ClaudeYour message, page text, screenshotsclaude.ai, under your account
Your serverThe chat, page text, imagesYour server (and whatever model it uses)
Claude Code, Cursor, OpenCodeThe chat and page textThe Bridge on your computer, then Anthropic, Cursor or OpenCode through their apps
OpenRouter, Gemini, OpenAI, GroqThe chat, page text, imagesThat company's API, under your key
Local modelThe chat, page text, imagesThe server you entered

Page text is read when you ask, not in the background. The Page switch in the panel turns it off per chat.

What stays in your browser

  • Settings, including API keys, your server's password and the Bridge token: storage.local, never synced.
  • Model lists, cached for six hours so the picker opens fast.
  • Chat history: storage.local, up to 300 chats. Turn it off or delete it in Settings → Data & privacy.

What ChroMind never does

  • No analytics, telemetry or ads. There's no ChroMind server to send anything to.
  • Answers can't load remote images or scripts: the Markdown renderer drops raw HTML and images, so a page can't sneak data out through an answer.
  • The selection toolbar only reads what you select, and only when you click it.
  • On this docs site, ChroMind marks the page with its version number so the install page can tell you whether you're up to date. That's all it shares, and only with this site.
