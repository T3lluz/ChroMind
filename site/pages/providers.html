Claude (claude.ai login)

If you're signed in to claude.ai in the same browser, ChroMind uses that login. Requests go straight from the extension to claude.ai, like the web app, so it counts against your plan's usage the same way.

  • Model: Account default uses whatever claude.ai would. Paid plans can pick Opus 5.5, Sonnet 5.5, Haiku 5.5 or Fable 5.1.
  • History: each ChroMind chat becomes one claude.ai conversation named ChroMind · …, so you can continue it on claude.ai (there's an Open in claude.ai link under each answer). Turn off Keep ChroMind chats in my claude.ai history and ChroMind asks for temporary chats and deletes them when you start a new chat or delete it from history.
  • Page text is sent as an attachment, so the conversation on claude.ai stays readable.

Signed out, or a browser check?

ChroMind shows Sign in to claude.ai with a button. If claude.ai shows a "checking your browser" page, open claude.ai in a tab once and try again.

Claude Code (via Bridge)

Uses the Claude Code CLI with the account it's signed in to, so your Claude Pro or Max subscription answers. It needs ChroMind Bridge running on your computer.

  • Models: sonnet, opus, haiku, fable (the CLI's aliases).
  • The Bridge runs claude -p with all tools turned off in an empty scratch folder, with no session saved. It answers; it can't touch your files.

Cursor (via Bridge)

Uses the Cursor CLI (cursor-agent) with your Cursor account and its model list: Auto, plus every model your plan has. Click Load models in settings to fill the list.

  • Runs in Cursor's read-only ask mode in an empty scratch folder.
  • Startup takes a few seconds per message; that's the CLI booting.

Hermes Agent

Connect like TileSmith / DailyDash: you@your-server and the SSH password. ChroMind Bridge tunnels to Hermes on that machine so the API can stay on localhost. For Hermes on this PC, use http://127.0.0.1:8642 and put API_SERVER_KEY in Password. Tool use shows up as chips above the answer. Full setup: Connect Hermes.

Switching mid-chat

You can change provider between messages. Stateless providers (Bridge, Hermes, OpenAI-compatible) get the whole chat each time. For Claude, ChroMind starts a claude.ai conversation and brings the earlier messages along.
