Your server

You seeDo this
Nothing answered at …Is the server on, and is this computer on the same tailnet or network? For Hermes on its own, add API_SERVER_HOST=0.0.0.0 to the server's ~/.hermes/.env and restart hermes gateway.
Hermes didn't accept that passwordThe password is Hermes' API_SERVER_KEY from ~/.hermes/.env, not your SSH password.
A server that worked stops answeringSettings → AI → Your server → Connect again. ChroMind looks again for what's there.

The panel and pages

You seeDo this
ChroMind can't read this pageBrowser pages, extension stores and the built-in PDF viewer are off-limits to extensions. Copy the text in, or use a screenshot.
Firefox: no page text, menus missingSettings → Get started shows Allow access to websites if Firefox hasn't granted it. Click it.
YouTube answers without a transcriptThe video has no captions, or YouTube changed its transcript panel. ChroMind falls back to the page text.
No selection toolbarCheck Settings → Behavior: the toolbar switch and the per-site list. It also skips text fields.
