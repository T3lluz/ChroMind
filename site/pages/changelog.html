0.3.1 · 2026-10-18

Things that should have just worked now do.

  • Fixed: right-click actions did nothing when the panel had been open for a while. The browser puts ChroMind's background to sleep after about 30 seconds, which cut the panel's connection; requests now reach the open panel anyway.
  • Fixed: Continue in side panel on the answer card now opens the chat in the panel, in Firefox too. If the panel can't open, the chat opens in a tab instead of nothing happening.
  • YouTube links and timestamps seek the open video instead of opening a new tab, in the panel and on the answer card. Links to a page that's already open switch to its tab.
  • Updates in settings: Settings → Updates shows whether you're on the latest version. Firefox: Update now. Chromium: the new zip and a Reload ChroMind button. The panel mentions a new version once it's out.
  • Continue in side panel works with chat history turned off (the chat is kept until the browser closes).
  • Plainer look: no colored bars on the current item in the docs, settings, picker and chat list.

0.3.0 · 2026-10-18

A new AI picker, your server without the Bridge, and more providers.

  • AI picker: click the pill for providers down the left, their models on the right with makers' logos, depth chips (Low to Max, and Fast), Free badges and one search across everything. Providers that need setup say what's missing.
  • Your server, no Bridge: type the server's address and password, like DailyDash. ChroMind finds your dashboard (Hermes plus the Claude, Cursor and OpenCode logins on it) or Hermes' API by itself. If nothing answers, it shows the one line to add on the server.
  • New providers: OpenCode's free models (through the OpenCode app, or every model with a Zen key), OpenRouter, Gemini, OpenAI and Groq with an API key.
  • Claude Code depths: Opus, Sonnet, Haiku and Fable at five thinking depths.
  • The Bridge pairs by itself: no token to copy. It's only needed for Claude Code, Cursor and OpenCode's free models; node chromind-bridge.mjs install sets it up in one go.
  • Working indicator from OpenCode, with what's happening (Reading the page, Thinking, Using web_search) and a timer, in the panel and the selection card.
  • Answers say which model and provider wrote them. Errors come with a button to the right setting, and a command to copy when one fixes it.
  • Settings: one card per provider with its logo, what it needs and a Test button.
  • Fixed: switching providers in the picker could close it.
  • The 0.2 SSH login for Hermes is gone (browsers can't open SSH connections). Your saved server address carries over; click Connect once.

0.2.0 · 2026-10-17

Hermes server login matches TileSmith and DailyDash.

  • Hermes settings are now Address (you@your-server) and Password (SSH), instead of a raw API URL + key.
  • ChroMind Bridge opens an SSH tunnel to Hermes on the server, reads API_SERVER_KEY from ~/.hermes/.env, and proxies the chat (tool chips still stream).
  • Local Hermes still works: put http://127.0.0.1:8642 in Address and API_SERVER_KEY in Password.
  • Existing 0.1 settings with baseUrl / apiKey migrate automatically.

0.1.0 · 2026-10-17

First release.

  • Side panel (Chromium) and sidebar (Firefox, Zen) from one codebase, with the ChroMods look in mint and cyan.
  • Providers: Claude through your claude.ai login; Claude Code and Cursor through ChroMind Bridge; Hermes Agent; any OpenAI-compatible server.
  • Page context via Mozilla Readability, YouTube transcripts with clickable timestamps, extra tabs, screenshots and images.
  • Quick actions, slash commands and custom actions; right-click menus on pages, selections, links and images.
  • Selection toolbar with an inline answer card and hand-off to the panel.
  • Chat history with search and Markdown export, read aloud, address-bar keyword cm.
  • ChroMind Bridge: one-file local server for the claude and cursor-agent CLIs, with autostart.
  • Signed Firefox builds from AMO (unlisted) with self-hosted updates; docs site on GitHub Pages.
