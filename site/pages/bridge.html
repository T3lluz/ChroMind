Browsers can't start programs, so Claude Code and Cursor answer through ChroMind Bridge: a single Node.js file (no dependencies) that listens on 127.0.0.1:8765, runs the CLI you pick for each message and streams the answer back. Your logins stay inside the CLIs.

Set it up

  1. Have Node.js 20 or newer. Check with node -v. Get it from nodejs.org if needed.
  2. Sign the CLIs in once (only the ones you want): 
    claude auth login
cursor-agent login
    Don't have them? Install Claude Code · install the Cursor CLI.
  3. Get the Bridge. It's bridge/chromind-bridge.mjs in the repository, or download chromind-bridge.mjs into a folder you keep.
  4. Start it: 
    node chromind-bridge.mjs
    It prints a token and which CLIs it found: 
      ChroMind Bridge 0.1.0 on http://127.0.0.1:8765

  Token: 3fQx…(32 characters)
  Paste it in ChroMind → Settings → Bridge.

  Claude Code  2.1.288
  Cursor       2026.10.16-e3cb207
  5. Paste the token in ChroMind → Settings → Bridge. The status turns green and lists both CLIs. Then pick Claude Code or Cursor from the pill in the panel.

Start it with your computer

node chromind-bridge.mjs install
  • Windows: a hidden starter in your Startup folder (ChroMind Bridge.vbs).
  • macOS: a LaunchAgent (~/Library/LaunchAgents/com.chromind.bridge.plist).
  • Linux: a systemd user service (chromind-bridge).

Undo with node chromind-bridge.mjs uninstall. Other commands: token prints the token, status shows what it found.

How it keeps you safe

Web pages are untrusted text, and a page could try to tell the AI to do something. So the Bridge:

  • Listens on 127.0.0.1 only, and needs the token on every request.
  • Refuses any request from a web page (anything with an http(s):// Origin), so sites can't reach it.
  • Runs Claude Code with every tool off (--tools "", no MCP servers, no slash commands, no saved session).
  • Runs Cursor in read-only ask mode.
  • Runs each message in a fresh, empty scratch folder that's deleted afterwards.

The token lives in ~/.chromind/bridge.json. Delete that file and restart to get a new one.

Settings

Environment variableDefaultDoes
CHROMIND_BRIDGE_PORT8765Port (also "port" in bridge.json). Change the URL in ChroMind to match.
CHROMIND_BRIDGE_HOST127.0.0.1Bind address. Keep it local.
CHROMIND_CLAUDE_BINfound on PATHPath to claude
CHROMIND_CURSOR_BINfound automaticallyPath to cursor-agent
CHROMIND_BRIDGE_TIMEOUT300Seconds before a message gives up

API

The Bridge speaks the OpenAI chat API, so other local tools can use it too:

curl http://127.0.0.1:8765/v1/chat/completions \
  -H "Authorization: Bearer $(node chromind-bridge.mjs token)" \
  -H "Content-Type: application/json" \
  -d '{"model":"claude-code/sonnet","stream":true,"messages":[{"role":"user","content":"Hi"}]}'
EndpointReturns
GET /healthPublic liveness check
GET /v1/statusCLIs, versions, sign-in state, models
GET /v1/modelsclaude-code/sonnet, cursor/auto, …
POST /v1/chat/completionsStreaming (SSE) or plain JSON. Thinking arrives as reasoning_content, tool use as event: chromind.tool.
